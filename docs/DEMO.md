| 2:05–2:40 | If cloud configuration exists, sign in with the clearly identified, pre-approved **adult demo account**, submit the saved draft, review the server snapshot, and approve publication. Copy its actual URL or download QR. Open it on a second device.               |

If Supabase is unavailable, replace the publication step with the private preview and explain the disabled-publishing notice. Do not claim that a local preview is accessible from another device. Do not display a made-up public URL or QR. You can complete the local learning portion comfortably within three minutes; rehearsing the configured parent/second-device flow is necessary before a live jury presentation.

To demonstrate genuinely recorded activity, use **Qo‘lda qayd etilgan** and enter actual observed amounts with an adult. Never record forecast profit as earned money. Training records and real records remain separate.

For an offline presentation, open the production application and each intended module before disconnecting. Local development requires the dev server to keep running. Fallback answers are predefined lessons, not live AI.
