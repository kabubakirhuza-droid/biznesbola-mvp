Mahalliy o‘quv ma’lumotlarini ota-ona sahifasidan o‘chirish mumkin. Server ma’lumotlarini o‘chirish uchun loyiha administratoriga murojaat qilish talab qilinadi.

**BiznesBola — o‘quv ilovasi. Pul bilan bog‘liq qarorlarni kattalar bilan birga qiling.**

## По-русски

BiznesBola — учебное приложение. Имя или псевдоним, возрастная группа, аватар, мечта и учебный прогресс хранятся в этом браузере. Фамилия, школа, домашний адрес и телефон ребёнка не запрашиваются. Записи в тренировке не являются реальным заработком.

Для живого Роберта последние сообщения передаются через сервер в Anthropic. Не вводите личные данные. Учебные ответы при недоступном AI имеют отдельную пометку. Для публикации требуется подтверждённый сервером аккаунт взрослого. Профиль ребёнка не добавляется в публичную витрину. Родитель должен проверить, что в описаниях и фотографиях также нет личной информации.

Платежей, прямого общения с покупателями и организации встреч нет. Родитель может закрыть публикацию. Уже просмотренную информацию нельзя удалить с устройства посетителя. Локальные учебные данные удаляются на странице родителей. Для удаления серверных данных требуется обращение к администратору проекта.

**BiznesBola — учебное приложение. Решения о деньгах принимайте вместе со взрослыми.**

## Before serving real children

This hackathon implementation does not claim COPPA, GDPR-K, or any jurisdictional compliance. Obtain qualified review for the applicable launch jurisdiction. Implement verified parental consent and revocation records, an age-appropriate data notice, retention schedules, parental access/export/deletion requests, processor agreements, data-transfer review, account recovery, security monitoring, and handling of user-generated text/images. Email confirmation and an administrative allowlist are authentication controls, not by themselves proof of informed legal consent.

The parent enrollment table has no self-service browser write policy. Operators must document their external adult verification process. Use clearly fictional data for the demonstration. No public inquiry/contact option is enabled. Before enabling one, separately review adult-only access, consent, abuse handling, and retention.
